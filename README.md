# AI-Powered Movie Review Sentiment Analysis

## Project Overview

This project uses a fine-tuned DistilBERT model to classify movie
reviews as Positive or Negative.

## Technologies Used

- Python
- PyTorch
- Hugging Face Transformers
- DistilBERT
- IMDb Dataset
- Streamlit
